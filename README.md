# AACHIP-ATMEL-AVR-PROGRAM

AACHIP ATMEL AVR PROGRAM 是針對 Atmel／Microchip AVR 微控制器的燒錄工具，提供韌體寫入與相關操作介面，協助進行嵌入式系統開發、測試及維護。

支援的晶片型號、燒錄介面、檔案格式及功能，請參考各版本發布說明。

## 應用情境

- AVR 微控制器韌體燒錄與更新。
- 開發板及自製電路板的程式下載。
- 韌體開發、教學實驗與硬體維護。

## 軟體下載

請前往本儲存庫的 **Releases** 頁面，下載安裝包並閱讀對應版本的使用說明。

## 基本使用流程

1. 安裝軟體及燒錄硬體所需的驅動程式。
2. 確認目標 AVR 型號受目前版本支援。
3. 依燒錄介面接線說明連接目標板，確認供電、電壓與接地。
4. 啟動軟體，選擇燒錄裝置及目標晶片。
5. 載入適用的韌體檔案，確認設定後執行燒錄。
6. 若版本提供驗證功能，請完成資料驗證後再執行目標程式。

## 使用注意事項

- 不同 AVR 系列使用的燒錄介面可能不同，請依目標晶片規格接線。
- 燒錄器與目標板的 I/O 電壓必須相容。
- 燒錄期間請保持供電及連線穩定。
- 若操作涉及晶片清除，請先確認是否需要備份既有資料。
- 若版本提供 Fuse／Lock Bits 設定，修改前請詳閱晶片資料手冊；錯誤設定可能影響時脈、後續燒錄或讀取能力。
